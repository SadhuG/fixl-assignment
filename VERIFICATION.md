# TaskHive verification checklist

- **Date:** 2026-09-30
- **Environment:** local stack, not production. The app is **not deployed yet**, so there are no production URLs.
  - Web: Vite dev server, `http://localhost:5173` (proxies `/api` to the API)
  - API: Express on `http://localhost:4000`, run with `node --env-file-if-exists=.env src/server.js`
  - DB: in-memory MongoDB (mongodb-memory-server) on port 27018, loaded with `npm run seed`
  - Browser: Chromium, driven through Playwright; Lighthouse 13.5.0 in headless Chrome
- **Deferred (needs a deployment):** the Vercel `/api` rewrite, the `Secure`/`SameSite=None` cookie over HTTPS, the Render cold start, and Safari/VoiceOver. These are marked "deferred: not deployed" below.

## Known limitations

- **List/Board view toggle at 360 px:** each segment is 36 px tall (`h-9`) inside a 42 px group, so it's under the 40 px target. It passes WCAG 2.5.8 (24 px). Making it 40 px changes the toolbar's height relative to New task, which is a design call, so it's left as is.
- **Task title buttons:** the row and card title is a text-style button that spans the full row width but is only about 22 px tall. The row's Actions menu (40 × 40) also has Open. Growing the hit area needs a layout change, so it's left as is.
- **Deferred until deployment:** the Vercel rewrite, the `Secure` cookie over HTTPS, the Render cold-start and suspend check (5.1 in production), and Safari/VoiceOver. Repeat these checks against the production URLs once deployed.
